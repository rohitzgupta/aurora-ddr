# Aurora DDR

Database Diagnostic Report (DDR) generator for
Amazon Aurora PostgreSQL.

## Features

- Wait Event Analysis
- Blocking Session Analysis
- Top SQL Analysis
- Connection Analysis
- Vacuum Analysis
- Database Health Summary
- HTML Report Generation

## Prerequisites

- Python 3.11+
- Aurora PostgreSQL

## Installation

git clone ...
cd aurora-ddr

pip install -r requirements.txt

## Usage

python ddr.py

## Output

report.html
